# Code of Conduct

## Our standard

Be respectful, constructive, and considerate. Focus feedback on ideas and code, welcome contributors of different experience levels, and assume good intent while communicating clearly.

Harassment, discrimination, personal attacks, doxxing, and other abusive behavior are not accepted in project spaces.

## Enforcement

Maintainers may edit or remove contributions and restrict participation when behavior violates this standard. Report conduct concerns privately to the repository owner through GitHub rather than opening a public issue containing sensitive details.
